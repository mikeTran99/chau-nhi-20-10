# Châu Nhi — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Build and show a cinematic, romantic local demo celebrating Nguyễn Hoàng Châu Nhi on 20/10/2026, from Trần Lê Minh Trung.

**Architecture:** A static Vietnamese page with progressive enhancement. HTML carries the complete story; CSS carries visual direction and most motion; JavaScript adds the envelope, photo viewer, canvas atmosphere, audio, and finale. Original photos remain untouched; no external runtime dependencies or network services.

**Tech Stack:** HTML, CSS, browser JavaScript, Canvas 2D, Web Audio, Node standard library for local preview and tests.

**Spec:** `docs/superpowers/specs/2026-10-20-chau-nhi-design.md`

## Global Constraints

- Names: Nguyễn Hoàng Châu Nhi and Trần Lê Minh Trung.
- Occasion: Ngày Phụ nữ Việt Nam, 20/10/2026.
- All 17 original images remain intact and appear in the album.
- No backend, analytics, form submission, external runtime dependency, or invented history.
- Respect `prefers-reduced-motion`; stop decorative loops and audio when hidden.
- Demo first. Do not push to GitHub or publish before the user reviews the demo.

## Review Focus

1. Narrow phones and long Vietnamese names: no horizontal overflow or clipped controls.
2. JavaScript disabled or image failing: the letter and navigation remain readable.
3. Reduced motion and hidden tab: no persistent canvas loop, parallax, or forced audio.
4. Keyboard photo navigation: Escape closes, arrows navigate, and focus returns to the trigger.
5. Repeated finale/audio clicks: particle count stays bounded and audio never stacks.

## File Map

- `index.html`: six story chapters, semantic navigation, letter, photo viewer dialog, controls.
- `styles.css`: noir/ivory/rose/champagne visual system, responsive composition, motion tokens and reduced motion overrides.
- `app.js`: progressive interactions, gallery data, reveal/parallax, bounded canvas particles, ambient melody.
- `server.mjs`: loopback-only static preview using Node standard library, safe URL resolution, GET/HEAD and content types.
- `tests/site.test.mjs`: Node assertions for real assets, required content, and safe preview requests.
- `package.json`: dependency-free `start` and `test` scripts.
- `README.md`: run command, customization locations, demo limitations, publishing status.
- `.gitignore`: ignore logs and test output; do not ignore original photos.

**Interfaces:** JavaScript reads existing `[data-photo]` triggers and their nested image sources; no second hand-maintained image catalog. `openPhoto(index)` updates the dialog image and counter. `setMotion()` applies a root reduced-motion state, using OS preference as an override. `burst(x, y)` adds a capped one-shot particle batch to the shared canvas.

- [ ] Implement envelope opening with keyboard-compatible buttons and a skip option; the gift is never locked behind audio permission.
